# League Radio

Audio-only esports radio for Windows and Android. Plays the Twitch audio-only stream (no video data),
shows the Worlds schedule in your local time zone, and keeps every score it has seen.

- `league_radio.pyw` - Windows app source (`League Radio.exe` is the packaged build)
- `android/` - Android app source (Kotlin, Media3)
- `docs/` - download page (GitHub Pages) with the APK and EXE
- `schedule_snapshot.json` - bundled schedule and results used when offline

Unofficial fan project. Not affiliated with Riot Games or Twitch.
