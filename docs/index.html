INSTALL ON ANDROID

  1. Open this page on your phone and tap the Android button.
  2. Open the downloaded file. If asked, allow installs from your browser.
  3. Open League Radio and press play.

WHAT IT DOES

  • Streams only the audio of the broadcast, so it uses a small fraction of the data of video.
  • Full schedule in your own time zone, detected automatically.
  • Keeps every score so you can look back at past games.
  • Test button plays any similar live stream, so you can check it works before a match.
